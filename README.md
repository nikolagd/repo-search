## Harvest repozitorijuma



### Podešavanja

Kloniranje

```bash
git clone https://github.com/nikolagd/repo-search.git
cd repo-search
```

Kreairanje i aktivacija virtuelnog okruženja (venv):
```bash
python -m venv .venv
.venv\Scripts\activate
```
Instaliranje dependencija:
```bash
pip install -r requirements.txt
```
